# SipilPDF

SipilPDF is a build of [Open PDF Studio](https://github.com/OpenAEC-Foundation/open-pdf-studio) (OpenAEC Foundation,
LGPL-3.0-or-later) for SipilStock Apps: <https://sipilstock.com/sipilpdf/>.

**This repository is generated.** The rebrand kit (patches, icons, packaging) lives in
<https://github.com/zlabx/Apps> under `rebrand/openpdfstudio/`; every build of the SipilStock web and desktop
versions is committed here as one commit with a `build-<key>` tag, so the source of what is deployed is public.
Do not edit it here: the next build overwrites everything.

  complete corresponding source.
